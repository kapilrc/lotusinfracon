# Lotus Infracon

**Premium Construction Equipment Rental Services**

Lotus Infracon is a professional website for a construction equipment rental company based in Pune, Maharashtra, India. The company specializes in providing precision rental solutions for India's infrastructure projects, serving Tier-1 contractors across the nation.

## About

The website showcases Lotus Infracon's fleet of construction equipment available for rental, including:

- **Concrete Pumps** — High-performance pumping solutions
- **Construction Equipment** — Heavy machinery for infrastructure projects
- **Scaffolding Systems** — Safety-certified scaffolding rental
- **Pipes Rental** — Industrial pipe solutions

## Tech Stack

- [Next.js](https://nextjs.org/) 16 (App Router)
- [React](https://react.dev/) 19
- [TypeScript](https://www.typescriptlang.org/)
- [Tailwind CSS](https://tailwindcss.com/) 4
- [Radix UI](https://www.radix-ui.com/) — Accessible component primitives
- [Lucide Icons](https://lucide.dev/)
- [pnpm](https://pnpm.io/) — Package manager
